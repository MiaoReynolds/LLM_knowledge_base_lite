# AI Knowledge System

This vault is an AI-assisted knowledge system.

---

## Agent Entry Point (IMPORTANT)

If you are an AI agent:

1. Start by reading:
   → `[[03_SYSTEM_GUIDE/README.md]]`

2. Then read:
   → `[[03_SYSTEM_GUIDE/SYSTEM_RULES.md]]`

3. Do NOT scan the entire vault by default.

Use layered access:
- index → summary → full notes
- human browse tree → topic category page → source notes
- topic map → local topic page → summaries + source notes

When organizing new notes, maintain the full chain:
- source note → summary
- summary → local topic page
- local topic page → source note
- root/topic indexes → category/topic pages
