Open-source templates should keep this as a template.
User vaults should generate their own local profile after category generation or refactor.

## Category Design Principle

This vault uses one-level `/00_RAW/<category>/` folders for source-note storage and human-recognizable grouping.
The human browse tree is:

`README_HUMAN.md -> /04_TOPIC_MAP/<theme>/<category>.md -> source notes + summary links`

Categories should reflect this user's actual retrieval habits and note distribution.
Do not copy another user's category profile blindly.
