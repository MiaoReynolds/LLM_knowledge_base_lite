- “修复 RAW 与 Summary 对应关系”
- “检测孤儿 summary”
- “批量清理孤儿 summary”

`“整理文章”` uses:
- `/03_SYSTEM_GUIDE/skills/organize_articles.md`

`“初始化知识库”`, `“生成分类文件夹”`, or `“重构分类系统”` uses:
- `/03_SYSTEM_GUIDE/skills/generate_category_system.md`
- warn that category generation/refactor may consume many tokens on large vaults
- default to proposal/dry-run before applying large moves

`“重新整理已处理文章”` uses:
- `/03_SYSTEM_GUIDE/skills/reorganize_article.md`

`“修复链接”` uses:
- `/03_SYSTEM_GUIDE/skills/repair_links.md`

`“更新人眼目录”` or `“刷新主题地图”` should refresh:
- `/00_RAW/<category>/_目录.md`
- `/04_TOPIC_MAP`
- source -> summary -> topic links
